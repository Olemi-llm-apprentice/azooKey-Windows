## 2. 実装済み機能

### 2.1 ライブ変換

**概要**: 入力と同時にリアルタイムで変換候補を表示し、自動的に最適な候補を適用する機能。

**動作仕様**:
1. ユーザーがローマ字を入力
2. ローマ字→ひらがな変換（roman2kana）
3. 変換エンジンが候補を生成
4. 最上位候補がプレビューとして表示
5. 入力継続時は候補が更新され続ける

**状態遷移**:

```
                    ┌─────────────────────────────────────┐
                    │                                     │
                    ▼                                     │
┌──────────┐  文字入力   ┌──────────────┐  Space/Tab/↓  ┌──────────────┐
│   None   │───────────▶│  Composing   │──────────────▶│  Previewing  │
│          │            │  (入力中)    │               │  (候補選択)  │
└──────────┘            └──────────────┘               └──────────────┘
     ▲                        │ │                           │ │
     │                        │ │                           │ │
     │  Escape/確定           │ │ ←/→ (カーソル移動)        │ │ ↑/↓ (選択変更)
     │                        │ │                           │ │
     └────────────────────────┘ └───────────────────────────┘ │
                    ▲                                         │
                    │              Enter (確定)               │
                    └─────────────────────────────────────────┘
```

**関連コード**:
- `crates/client/src/engine/composition.rs` - 状態管理
- `server-swift/Sources/azookey-server/azookey_server.swift` - 変換処理

### 2.2 Zenzai ニューラルかな漢字変換

**概要**: Transformer Decoderベースのニューラル言語モデルを利用した高精度変換システム。

**技術詳細**:
- モデル形式: GGUF (llama.cpp互換)
- モデルファイル: `zenz.gguf`
- 推論ライブラリ: llama.cpp

**バックエンド選択**:

| バックエンド | 要件 | 速度 |
|-------------|------|------|
| CPU | なし | 遅い（非推奨） |
| CUDA | CUDA Toolkit 12系 | 高速 |
| Vulkan | GPUドライバ標準付属 | 高速 |

**設定項目**:

```json
{
    "zenzai": {
        "enable": true,
        "profile": "山田太郎、数学科の学生。",
        "backend": "vulkan"
    }
}
```

**プロファイル機能**:
- ユーザー情報を自然言語で記述
- 変換時に文脈として考慮される
- 例: 職業、専門分野、よく使う語彙などを指定

**関連コード**:
- `server-swift/Sources/azookey-server/azookey_server.swift` - `getOptions()` 関数
- `frontend/src/pages/zenzai.tsx` - 設定UI

### 2.3 入力モード切替

**概要**: かな入力モード(あ)と英字入力モード(A)の切り替え。

**切り替え方法**:
- 半角/全角キー
- 言語バーからの選択

**状態表示**:
- 入力モードインジケータが「あ」または「A」を表示

**関連コード**:
- `crates/client/src/engine/input_mode.rs` - モード定義
- `crates/ui/src/indicator.rs` - インジケータ表示

### 2.4 候補ウィンドウ

**概要**: 変換候補をリスト表示するポップアップウィンドウ。

**UI仕様**:
- 最大5件の候補を表示
- 選択中の候補はハイライト表示
- ダークモード対応
- ドロップシャドウ付きの角丸デザイン

**キー操作**:

| キー | 動作 |
|------|------|
| ↑ / ↓ | 候補選択 |
| Space / Tab | 次の候補 |
| Enter | 確定 |
| Escape | キャンセル |
| 数字キー | 候補番号で選択 |

**関連コード**:
- `crates/ui/src/candidate.rs` - ウィンドウ生成・HTML定義

### 2.5 ファンクションキー変換

**概要**: F6〜F10キーによる文字種変換。

| キー | 変換 | 例 |
|------|------|-----|
| F6 | ひらがな | あいう |
| F7 | カタカナ | アイウ |
| F8 | 半角カタカナ | ｱｲｳ |
| F9 | 全角英数 | ａｉｕ |
| F10 | 半角英数 | aiu |

**関連コード**:
- `crates/client/src/engine/composition.rs` - `UserAction::Function` ハンドリング
- `crates/client/src/engine/text_util.rs` - 文字変換関数

## 3. 未実装機能

### 3.1 履歴学習機能 【優先度: 高】

**概要**: ユーザーが選択・確定した変換結果を学習し、次回以降の変換で優先的に表示する。

**macOS版仕様**:
- 変換履歴をローカルに保存
- 同じ読みに対して過去に選択した候補を優先
- 学習データの削除機能

**必要な実装**:
1. 学習データの保存形式定義
2. 確定時の学習データ記録処理
3. 変換時の学習データ参照処理
4. AzooKeyKanaKanjiConverterの`learningType`パラメータ活用

**関連するAzooKeyKanaKanjiConverter設定**:
```swift
ConvertRequestOptions(
    learningType: .inputAndOutput,  // 現在は .nothing
    memoryDirectoryURL: URL(filePath: "./memory"),
    // ...
)
```

### 3.2 ユーザー辞書機能 【優先度: 高】

**概要**: ユーザーが独自の読み・単語ペアを登録できる機能。

**macOS版仕様**:
- 読み、単語、品詞を指定して登録
- CSVでのインポート/エクスポート
- システム辞書との連携

**必要な実装**:
1. 辞書登録UI（設定アプリに追加）
2. 辞書データの永続化（JSON/SQLite）
3. 変換時の辞書参照
4. インポート/エクスポート機能

### 3.3 いい感じ変換 【優先度: 中】

**概要**: LLMを活用した高度な変換機能。「いい感じに」と入力すると、文脈に応じた変換候補を提示。

**macOS版仕様**:
- 絵文字推薦
- 英語校正
- 文章フォーマット変換
- Tunerとの連携

**必要な実装**:
1. 特殊キーワードの認識処理
2. LLM推論呼び出し
3. 結果の候補リストへの統合

### 3.4 個人最適化システム (Tuner) 【優先度: 中】

**概要**: ユーザーの入力パターンに基づいてモデルを最適化するシステム。

**参考**: [Tuner リポジトリ](https://github.com/azooKey/Tuner)

**必要な実装**:
1. Tunerとの連携プロトコル実装
2. 入力データの収集・送信
3. 最適化モデルの適用

### 3.5 予測変換 【優先度: 中】

**概要**: 入力途中の段階で次に入力される可能性の高い単語を予測・提示する。

**必要な実装**:
1. `requireJapanesePrediction`の有効活用
2. 予測候補の表示UI
3. 予測候補選択時の処理

### 3.6 テーマ変更機能 【優先度: 低】

**概要**: 候補ウィンドウの外観をカスタマイズできる機能。

**必要な実装**:
1. テーマ設定UI
2. CSSテーマの切り替え機構
3. テーマのプリセット（ライト/ダーク/カスタム）

### 3.7 辞書インポート/エクスポート 【優先度: 低】

**概要**: ユーザー辞書データの入出力機能。

**対応フォーマット案**:
- CSV (Microsoft IME互換)
- JSON (azooKey独自形式)

### 3.8 AZIK入力サポート 【優先度: 低】

**概要**: AZIK（拡張ローマ字入力方式）のネイティブサポート。

**必要な実装**:
1. AZIKルールの定義
2. 入力変換ルールの適用
